# 设计

## Planner

规划器：根据用户的任务制定一个执行器可执行的分步骤计划。

1. 写好规划器的提示词，明确最大步骤数和去掉markdown围栏等等要求；
2. 给模型上api级别的输出格式约束，和pydantic一起保证模型输出符合要求；
3. 模型输出校验失败时带上错误信息重试一次，两次上抛错误，保证不无限循环；
4. **重规划**时带上上次计划和黑板信息。

## Executor

执行器：执行规划器规划的计划。

1. 允许**重规划**一次，如果执行结果有问题；
2. 将计划分层，同一层互不依赖，可异步执行；
3. 保留串行执行和异步执行两种方法；
4. 保留原 agent loop，在原返回结果上重新提取新的结果。

# 验收

## 1. 规划器

三个任务测试规划器：

- 现在几点：一步计划；
- 北京和上海哪个更暖和：三步计划，前两步查两个城市天气（无依赖），最后一步对比总结；
- 查北京、上海、深圳的天气并对比谁更暖和：四步计划，前三步查三个城市天气（无依赖），最后一步对比总结。

规划器（planner）返回结果正常，通过测试。
